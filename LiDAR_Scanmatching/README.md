'./pylidar_de.py' は，もともとは生活と技術の講義用デモとして作成した．
2つのスキャンデータのマッチングより，相対姿勢を計算する，
いわゆるLiDAR オドメトリである．

スキャンマッチングの評価には，オリジナルのDE+ガウシアンフィルタを用いている．
これが非常にうまく働いており，その操作をキーボードからのトリガーにより
連続的に動作するように改良したのが，本プログラムである．

また，合わせて，もともとの './pylidar_2x_measurement_cv.py' を改良し，
スキャンデータを保存することとし，LiDARデータ収集プログラムとした．
coyomiには，'../data_collect.cpp' というデータ収集プログラムが存在するが，
coyomi本体を動力走行させながら計測するプログラムであり，
単体LiDARには対応していなかった．
より簡便な方法として，こちらのPython版を復活させた形となる．

今後，LiDAR単体でのデータ計測を考えているならば，こちらのプログラムの使用を
考えてみるとよい．
